# 見積もり作成機能：費用選択・金額編集 要件

## 目的

工事項目ごとに材料費と労務費を選択し、必要な費用だけを見積金額へ反映できるようにする。

## 機能要件

### 費用区分の選択

- 各見積明細に「材料費」「労務費」のチェックボックスを設置する。
- 新規明細は両方を選択した状態とする。
- 材料費だけを選択した場合は労務費を計算から除外する。
- 労務費だけを選択した場合は材料費を計算から除外する。
- 両方を選択した場合は材料費と労務費を計算へ含める。
- 両方を未選択にした場合は、明細経費を含めてその明細全体を0円として合計から除外する。
- 明細経費は選択された工事に共通する付随費として、材料費または労務費のどちらかが選択されている場合に加算する。

### 編集できる項目

- 名称
- 仕様
- 数量
- 単位
- 材料費
- 労務費
- 明細経費
- 備考
- 諸経費率
- 労務費合計

単価、明細金額、工種計、直接工事費、諸経費、総額は直接編集せず、入力値から自動計算する。

労務費合計を編集した場合は、労務費が選択されている各明細の労務費を現在の比率で配分し直す。現在の労務費合計が0円の場合は、対象明細へ均等配分する。これにより明細、工種計、直接工事費、総額の整合性を維持する。

### 計算

```text
選択原価 = 選択された材料費 + 選択された労務費
単価 = (選択原価 + 明細経費) × 顧客係数
明細金額 = 数量 × 単価
直接工事費 = 明細金額の合計
諸経費 = 直接工事費 × 諸経費率（100円未満切り捨て）
総額 = 直接工事費 + 諸経費
労務費合計 = Σ（数量 × 選択された労務費 × 顧客係数）
```

材料費と労務費がどちらも未選択の場合、単価と明細金額は0円とする。

### 保存・出力

- 費用区分の選択状態と編集後の金額を見積もりごとに保存する。
- localStorage利用時とSupabase利用時の両方で復元できること。
- 既存データに選択状態がない場合は、材料費・労務費の両方を選択済みとして扱う。
- プレビュー、印刷、PDF、Excel、CSVに同じ選択結果と計算結果を反映する。
- 未選択の材料費・労務費は帳票とエクスポート上で空欄にする。

### 消費税

既存帳票の「消費税は別途申し受けます」という運用を維持し、今回の変更では消費税を総額へ加算しない。

## 入力規則

- 数量、材料費、労務費、明細経費、諸経費率は0以上とする。
- 空欄は0として計算する。
- 数値欄をクリックまたはフォーカスしたときは、現在値を全選択する。
- 数値欄でBackspaceまたはDeleteを押したときは、現在値をクリアする。
- 空欄のままフォーカスを外した場合は、空欄化する直前の数値へ戻す。
- 金額は円単位で表示し、表示時は3桁区切りとする。
- 入力変更時に単価と各合計を即時再計算する。

## 完了条件

- 明細ごとに材料費と労務費を選択できる。
- 未選択費用が単価・明細金額・各合計から除外される。
- 編集した数量・単位・各費用が保存後に復元される。
- 旧データを開いても従来と同じ金額で表示される。
- プレビュー、PDF、Excel、CSVの金額が編集画面と一致する。
- PCとスマートフォンの両方で操作できる。

## 画面構成

- 基本情報と合計は常時表示する。
- その下を「単価を探す」「見積明細」の2タブに分ける。
- PCとスマートフォンで同じタブ構成を使用する。
- 「見積明細」タブには、選択中の明細件数と見積総額を表示する。
- 見積明細が存在する工種だけを表示し、未選択工種の空テーブルは表示しない。
- タブは画面上部へ追従し、縦にスクロールした場合も切り替えられるようにする。
- 検索結果から明細を追加した後も検索タブを維持し、複数項目を続けて追加できるようにする。
